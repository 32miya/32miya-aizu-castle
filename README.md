# 鶴ヶ城さんぽ（会津若松城）

会津若松の鶴ヶ城（若松城・福島県会津若松市・国史跡）を、スマホで歩いて巡れる3D散策アプリ。お城さんぽシリーズの一城です（大阪城さんぽ・熊本城さんぽと同じ作り）。

- **現代**: 赤瓦の天守閣（郷土博物館。地下の塩蔵〜最上階の展望層）、復元された走長屋・鉄門・南走長屋・干飯櫓、茶室麟閣、廊下橋、内堀と桜、北出丸・西出丸、三の丸の県立博物館、飯盛山（白虎隊十九士の墓・さざえ堂）、天寧寺、阿弥陀寺
- **江戸時代**: 白亜五層・赤瓦の天守、本丸御殿（大書院）、御三階、月見櫓・茶壺櫓、北出丸の追手門、郭内の武家屋敷（西郷頼母邸）、藩校日新館、七日町・大町の城下町
- **戊辰戦争（慶応4年・1868）**: 自動案内で10場面をたどる
  1. 会津、戦いに備える（新選組・土方歳三と天寧寺、白虎隊の調練）
  2. 母成峠の戦い（新選組・斎藤一）
  3. 白虎隊、出陣（滝沢本陣）
  4. 戸ノ口原の戦い
  5. 城下へ突入・北出丸の攻防（西郷頼母邸、山本八重の入城）
  6. 白虎隊、飯盛山
  7. 涙橋の戦い（娘子隊・中野竹子）
  8. 彼岸獅子入城（山川大蔵）
  9. 小田山の砲撃・籠城（照姫と城の女性たち、八重）
  10. 開城（泣血氈、八重の歌、斎藤一・土方歳三のその後）

公開: https://32miya.github.io/32miya-aizu-castle/

距離は実際より縮め、建物の配置と寸法は簡略化しています。飯盛山・小田山・涙橋・母成峠・戸ノ口原などの遠い場所は、大きく縮めて城の近くに置いています。記録の少ない部分（天守の内部・城下の家並み・兵の配置・せりふなど）は、言い伝えと想像で補った再現です。
